# Service workflow pictures

Place your real pictures in the service folder below. Use JPG, JPEG, PNG or WebP.
Name the four images `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg` (or the same numbers with another supported extension).
Restart the preview after adding images; rebuild before deploying. Empty stages display a clean placeholder.
Images are contained inside their frame so drawings are not cropped.

| Folder | 1: Client input | 2: First direction | 3: Detail / review | 4: Delivery |
| --- | --- | --- | --- | --- |
| exterior | Plan, measured sketch and references | Rough model / facade | Detailed model | Final render |
| interior | Plan and references | Moodboard with leader lines / base model | Detailed interior model | Final render |
| walkthrough | Approved plan / model | Camera route / storyboard | Detailed scene / test frame | Final film still |
| plans | Plan or measured sketch | Layout draft | Detailed plan | Final sheet |
| drawings | Plot sketch with outer dimensions | Floor plan | Elevations, sections, working drawings / MEP | Drawing booklet |
| consultation | Plans / photos / brief | Initial recommendations | Annotated design options | Agreed action plan |

Until stage 4 pictures are provided, exterior, interior and walkthrough use their existing service picture clearly labelled as a portfolio example.
